# Biomaterial Performance Project

This repository contains the interactive dashboard and research notebook for “Experimental Validation of an AI Model for Biomaterial Performance.”

- Dashboard: [Open the live project UI](https://jaydudhale.github.io/Biomaterial-performance-project/)
- Notebook: [Download/open the project notebook](experimental_validation_biomaterial_model.ipynb)

## Run the notebook

Install Python packages with `pip install numpy pandas matplotlib`. The notebook currently points to the original Mac data folder. Update `DATA_ROOT` to the dataset's location on your computer before running its cells.

## Website deployment

GitHub Pages publishes the site from the `main` branch root. The dashboard file is `index.html`; the notebook is kept beside it so the dashboard link works.
